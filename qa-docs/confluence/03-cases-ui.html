TC-UI-01Отображение категорий и товаров на главной
Приложение запущено, база наполнена демо-данными		Высокий1. Открыть http://localhost:3000
2. Проверить вкладки категорий
3. Проверить количество карточек		Отображаются 6 вкладок (Всё меню + 5 категорий) и 18 карточек товаровE2E-02
TC-UI-02Фильтрация товаров по категории
Открыта витрина		Средний1. Нажать вкладку «Напитки»
2. Посчитать карточки		Показано 4 товара категории «Напитки», товары других категорий отсутствуютE2E-03
TC-UI-03Карточка товара содержит цену, вес и фото
Открыта витрина		Средний1. Найти карточку «Шаурма классическая»
2. Проверить цену, вес, наличие изображения		Цена 280 ₽, вес 350 г, отображается фотография блюда, кнопка «В корзину» активнаE2E-04
TC-UI-04Добавление товара в корзину
Корзина пуста		Высокий1. Нажать «В корзину» на товаре
2. Подтвердить добавление		Счётчик корзины увеличивается, товар появляется в корзинеE2E-10
TC-UI-05Расчёт стоимости с дополнителями
Корзина пуста		Высокий1. Добавить «Шаурма классическая»
2. Выбрать допы «Двойное мясо» и «Дополнительный сыр»
3. Открыть корзину		Стоимость позиции 450 ₽ (280 + 120 + 50), допы отображаются под названиемE2E-11
TC-UI-06Изменение количества и пересчёт суммы
В корзине товар «Шаурма с говядиной»		Средний1. Добавить товар в количестве 3
2. Проверить итоговую сумму		Количество 3, сумма 1 020 ₽ (340 × 3)E2E-12
TC-UI-07Уменьшение количества до нуля удаляет позицию
В корзине одна позиция		Средний1. Нажать «−» один раз
2. Проверить корзину		Позиция удалена, отображается «Корзина пуста», счётчик равен 0E2E-13
TC-UI-08Сохранение корзины после перезагрузки
В корзине есть товар		Низкий1. Перезагрузить страницу (F5)
2. Открыть корзину		Товар и количество сохранились (localStorage)E2E-15
TC-UI-09Вход по номеру телефона с кодом из SMS
Пользователь не авторизован		Высокий1. Нажать «Войти»
2. Ввести номер +7 900 777-66-55
3. Нажать «Получить код»
4. Ввести код из подсказки
5. Нажать «Войти»		В шапке появляется имя пользователя, доступны «Мои заказы» и «Выйти»E2E-40
TC-UI-10Неверный код из SMS не пускает в аккаунт
Код запрошен		Высокий1. Ввести 0000
2. Нажать «Войти»		Ошибка «Неверный код», пользователь остаётся неавторизованнымE2E-41
TC-UI-11Валидация телефона при оформлении заказа
В корзине товар		Высокий1. Открыть оформление
2. Ввести телефон «abc»
3. Подтвердить заказ		Ошибка валидации с указанием поля phone, заказ не созданE2E-22
TC-UI-12Минимальная сумма заказа с доставкой
В корзине товар на 40 ₽		Высокий1. Выбрать способ «Доставка»
2. Заполнить адрес
3. Подтвердить		Сообщение «Минимальная сумма заказа с доставкой — 500 руб.», заказ не созданE2E-23
TC-UI-13Оплата заказа банковской картой
Заказ создан		Высокий1. Ввести карту 4111 1111 1111 1111, срок 12/30, CVV 123
2. Нажать «Оплатить»		Заголовок «Оплата прошла», сумма и маска карты •1111, статус заказа обновляется автоматическиE2E-40
TC-UI-14Отказ банка при оплате
Заказ создан		Высокий1. Ввести карту 0000 1111 2222 3333
2. Нажать «Оплатить»		Сообщение «Банк отклонил платёж», заказ остаётся в статусе PENDINGE2E-42
TC-UI-15Уведомление о готовности заказа
Заказ оплачен, покупатель на экране заказа		Высокий1. Админ переводит заказ: CONFIRMED → COOKING → DELIVERING
2. Подождать до 15 секунд		Появляется баннер «Ваш заказ готов!» и всплывающее уведомление, статус «В доставке»E2E-40
TC-UI-16Вход в админ-панель и отображение статистики
Есть учётная запись администратора		Высокий1. Открыть /admin
2. Ввести admin@shawarma.ru / Admin123!
3. Нажать «Войти»		Отображаются 4 показателя статистики, таблица заказов и список товаровE2E-32
TC-UI-17Смена статуса заказа в админке
Есть заказ в статусе NEW		Средний1. Найти заказ в таблице
2. Нажать «Подтверждён»		Статус меняется на «Подтверждён», кнопки обновляются по допустимым переходамE2E-33
TC-UI-18Скрытие товара из меню
Администратор авторизован		Средний1. Найти товар «Морс клюквенный»
2. Нажать «Скрыть»
3. Открыть витрину в новой вкладке		Товар исчезает из витрины (17 карточек), остаётся в старых заказахE2E-35
