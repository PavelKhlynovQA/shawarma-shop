Вход

Откройте http://localhost:3000/admin и войдите: admin@shawarma.ru / Admin123!. Без авторизации показывается только форма входа.

Рабочее место

  • Четыре показателя: всего заказов, заказов сегодня, выручка, новых в очереди
  • Таблица заказов: ID, номер, клиент, способ получения, сумма, статус, кнопки действий
  • Топ товаров по продажам за всё время
  • Список меню с возможностью скрыть или вернуть товар

Жизненный цикл заказа

Текущий статусДоступные действияКогда нажимать
НовыйПодтверждён / ОтменитьСозвонились с клиентом
ПодтверждёнГотовится / ОтменитьЗаказ передан на кухню
ГотовитсяВ доставке / ОтменитьКурьер забрал заказ
В доставкеВыполнен / ОтменитьКлиент получил заказ
Выполнен / Отменён—Финальные статусы, менять нельзя

Кнопки показывают только допустимые переходы — ошибиться нельзя. Каждая смена статуса попадает в историю заказа.

Управление меню

  • «Скрыть» убирает товар из витрины, но сохраняет его в старых заказах
  • «Вернуть» снова показывает товар клиентам
  • Цена и описание меняются через API PATCH /api/admin/products/:id

Что делать при инциденте

СитуацияДействие
Клиент не получил заказНайти заказ по номеру, проверить статус и историю, связаться с курьером
Заказ завис в «Готовится»Перевести в «В доставке» после передачи курьеру
Клиент отменил заказНажать «Отменить» — статус станет финальным, оплата не возвращается автоматически
Товар закончилсяСкрыть его в админке — он исчезнет из витрины

Ограничения панели

  • Нет пагинации: отображаются последние 50 заказов
  • Нет фильтра по датам и поиска по номеру
  • Нет ролей кроме администратора
  • Возвраты не поддерживаются — только отмена до доставки
