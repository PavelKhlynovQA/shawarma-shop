1.0.0 — 14.11.2026

Первый релиз учебного проекта.

  • Витрина с категориями, фотографиями блюд и фильтром
  • Корзина с дополнителями и сохранением между сессиями
  • Оформление заказа: валидация, промокоды, минимальная сумма доставки
  • Оплата картой с имитацией отказа банка
  • Вход по номеру телефона с одноразовым кодом
  • Отслеживание статуса с автообновлением и уведомлением о готовности
  • Админ-панель: очередь заказов, смена статусов, управление меню, статистика
  • PostgreSQL в Docker и SQLite для локального запуска
  • 23 API-теста, 35 E2E, 5 визуальных, CI на GitHub Actions, отчёт Allure
  • Документация: Confluence-пространство QASHOP, 53 тест-кейса, 10 баг-репортов

Известные ограничения релиза

  • Оплата имитируется — реальный эквайринг не подключён
  • Код подтверждения возвращается в ответе API (демо-режим)
  • Заказ доступен по номеру без авторизации (BUG-005, открыт)
  • Создание заказа не обёрнуто в транзакцию (BUG-006, открыт)
  • Нет SMS-уведомлений и push — только уведомления в интерфейсе
