Общие правила

  • Базовый URL: http://localhost:3000, префикс /api
  • Формат: JSON, Content-Type: application/json
  • Авторизация: Authorization: Bearer <JWT>
  • Каждый ответ содержит заголовок X-Request-Id для трассировки
  • Ошибки в едином формате: { error: { code, message, details } }

Коды ответов

КодКогда
200Успешное чтение или изменение
201Создан заказ или пользователь
400Ошибка валидации, невалидный JSON
401Нет токена или он истёк
402Банк отклонил платёж
403Недостаточно прав
404Объект не найден
409Нарушено бизнес-правило
500Внутренняя ошибка
