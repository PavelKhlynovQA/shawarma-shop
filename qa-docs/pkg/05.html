Назначение разработки

Веб-приложение для приёма и обработки заказов шаурмичной. Работает в браузере, не требует установки. Доступно два интерфейса: витрина для клиента и админ-панель для сотрудника.

Требования к данным

  • Хранение заказов с историей статусов: каждая смена статуса фиксируется отдельной записью
  • Суммы заказа хранятся в целых рублях: subtotal, discount, total
  • Позиции заказа хранят снимок названия и цены на момент покупки
  • Промокоды учитывают лимит использований и срок действия
  • Одноразовые коды входа живут 5 минут и не более 5 попыток ввода

Требования к интерфейсу

  • Адаптивная вёрстка от 375 px, тёмная тема оформления
  • Все действия доступны без перезагрузки страницы
  • Ошибки показываются понятным текстом, а не кодом
  • Ключевые действия подтверждаются визуально (счётчик корзины, тосты)

Критерии приёмки системы

  • Сквозной сценарий «вход → корзина → оплата → уведомление» проходит без ошибок
  • Все автотесты зелёные: API 23, E2E 35, визуальные 5
  • Нет открытых дефектов уровня Blocker и Critical
  • Развёртывание одной командой: docker compose up
