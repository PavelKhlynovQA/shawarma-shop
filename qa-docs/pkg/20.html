Миграции

Схема применяется автоматически при старте: CREATE TABLE IF NOT EXISTS плюс догоняющие ALTER TABLE для недостающих колонок. Отдельных команд миграции не требуется.

Откат

  • Код: git checkout предыдущего тега и повторная сборка
  • Данные: восстановление из дампа pg_dump, снятого перед релизом
  • Быстрый откат контейнера: docker compose down && docker compose up -d с предыдущим образом
