## Готовые payload'ы

### Успешный заказ
```json
{
  "customerName": "Иван Тестов",
  "phone": "+7 900 123-45-67",
  "deliveryType": "delivery",
  "address": "Волгоград, ул. Мира, 15",
  "promoCode": "SHAWARMA10",
  "items": [{ "productId": 1, "quantity": 2, "extraIds": [1, 2] }]
}
```
Ожидание: subtotal 900, discount 90, total 810.

### Заказ ниже минимума
```json
{ "customerName": "Тест", "phone": "+79001234567", "deliveryType": "delivery", "address": "ул. Мира 1", "items": [{ "productId": 12, "quantity": 1 }] }
```
Ожидание: 409 `MIN_ORDER_AMOUNT`.

### Невалидный телефон
```json
{ "customerName": "Тест", "phone": "abc", "deliveryType": "pickup", "items": [{ "productId": 1, "quantity": 1 }] }
```
Ожидание: 400, `details[0].field = "phone"`.
