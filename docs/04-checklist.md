# Чек-лист регрессии «Шаурма-Мастер»

Отмечай `[x]` при прохождении. Полный прогон занимает ~40 минут вручную.

## 1. Запуск и окружение

- [ ] `npm install` проходит без ошибок
- [ ] `npm start` поднимает сервер на :3000
- [ ] Лог содержит строку с драйвером БД
- [ ] `/api/health` отвечает `{"status":"ok"}`
- [ ] `docker compose up` поднимает db + app
- [ ] DBeaver подключается к PostgreSQL
- [ ] Таблицы созданы: users, categories, products, extras, promocodes, orders, order_items, order_status_history

## 2. Витрина

- [ ] Открывается без ошибок в консоли
- [ ] Все 5 категорий видны
- [ ] Переключение категорий работает
- [ ] Карточка показывает веса и цену
- [ ] Острые блюда помечены
- [ ] Мобильная вёрстка (ширина 375 px) не ломается

## 3. Корзина

- [ ] Добавление товара увеличивает счётчик
- [ ] Повторное добавление увеличивает количество, а не создаёт дубль
- [ ] Товар с допами считается корректно
- [ ] Удаление и уменьшение количества работают
- [ ] Итог пересчитывается после каждого действия
- [ ] Корзина сохраняется после перезагрузки

## 4. Оформление

- [ ] Валидация имени (пустое — ошибка)
- [ ] Валидация телефона (буквы — ошибка)
- [ ] Адрес обязателен только для доставки
- [ ] Промокод применяется и отображается скидка
- [ ] Неверный промокод показывает понятную ошибку
- [ ] Минимум 500 ₽ для доставки срабатывает
- [ ] После заказа показывается номер и статус
- [ ] Корзина очищается после успешного заказа

## 5. Админка

- [ ] Без токена показывается форма входа
- [ ] Неверный пароль — сообщение об ошибке
- [ ] Статистика совпадает с данными в БД
- [ ] Список заказов отсортирован по дате (новые сверху)
- [ ] Кнопки статусов соответствуют текущему статусу
- [ ] Смена статуса обновляет таблицу
- [ ] Недопустимый переход показывает ошибку
- [ ] Скрытие товара убирает его из витрины

## 6. API и безопасность

- [ ] Все ошибки в формате `{error:{code,message,details}}`
- [ ] `X-Request-Id` присутствует в ответах
- [ ] Токен покупателя не даёт доступ к админке
- [ ] Истёкший токен возвращает 401
- [ ] `OPTIONS`-запрос возвращает 204
- [ ] Невалидный JSON возвращает 400 `INVALID_JSON`

## 7. Данные

- [ ] Сиды создают 18 товаров
- [ ] Повторный запуск не дублирует данные
- [ ] Промокод `used_count` увеличивается после заказа
- [ ] История статусов содержит все переходы
