# 🌯 Шаурма-Мастер — пространство проекта

Добро пожаловать! Это пространство Confluence для учебного проекта интернет-магазина шаурмы.

## Структура пространства

| Страница | Содержание |
|---|---|
| **Главная** (эта страница) | Навигация, состав команды, ссылки |
| Требования | User stories, критерии приёмки, бизнес-правила |
| Тест-план | Стратегия, окружения, критерии входа/выхода, риски |
| Тест-кейсы | 40 кейсов с шагами и ожидаемыми результатами |
| Баг-репорты | 8 воспроизведённых дефектов + шаблон |
| Отчёт о тестировании | Итоги релиза 1.0 |
| Онбординг | Как поднять проект за 10 минут |

## О проекте

**Шаурма-Мастер** — интернет-магазин шаурмы с доставкой и самовывозом.

- Витрина: http://localhost:3000
- Админка: http://localhost:3000/admin
- API: http://localhost:3000/api/health
- Репозиторий: локальный, ветка `main`

## Стек

Node.js 22+, Express 4, PostgreSQL 16 (Docker) / SQLite (локально), vanilla JS, Docker Compose, `node:test`.

## Как пользоваться этим пространством

1. Перед релизом обновляй **Отчёт о тестировании**.
2. Каждый новый баг — отдельная страница-ребёнок в разделе «Баг-репорты» с ID `BUG-XXX`.
3. Тест-кейсы храним таблицей, статус меняем через встроенный статус Confluence.
4. Вложения (скриншоты, логи) кладём в страницу бага.
