# Онбординг: как поднять проект за 10 минут

## Шаг 1. Требования

- Node.js 22 или новее (`node --version`)
- Docker Desktop (опционально, для PostgreSQL)
- DBeaver (опционально, для просмотра БД)

## Шаг 2. Установка

```bash
git clone <repo>
cd shawarma-shop
npm install
npm start
```

Открой http://localhost:3000 — витрина работает, база создана автоматически.

## Шаг 3. Проверка, что всё живо

```bash
curl http://localhost:3000/api/health
```

Ожидаемо: `{"status":"ok","dbDriver":"sqlite"}`

## Шаг 4. Запуск с PostgreSQL

```bash
docker compose up --build
```

## Шаг 5. Подключение DBeaver

1. New Database Connection → PostgreSQL
2. Host `localhost`, Port `5432`, Database `shawarma`
3. User `shawarma`, Password `shawarma`
4. Проверь таблицы: `orders`, `order_items`, `products`

## Шаг 6. Прогон тестов

```bash
npm test
```

Ожидаемо: 24 теста, 0 падений.

## Частые проблемы

| Симптом | Решение |
|---|---|
| `EADDRINUSE :3000` | Порт занят: `PORT=3001 npm start` |
| `Cannot find module 'express'` | Не выполнен `npm install` |
| Docker: port 5432 busy | Останови локальный PostgreSQL |
| `EPERM` при `npm test` | Запусти без песочницы или `node --test --test-isolation=none tests/` |
