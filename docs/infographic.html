Побочный квест: билеты РЖД

исследование

Ты просил найти билеты Волгоград → Краснодар. Сайт не открывался — разобрался почему.

  • Причина: РЖД перешёл на сертификат Минцифры, а его нет в хранилище Windows
  • Браузер поднять не удалось — данные взял из партнёрского фида Яндекс.Расписаний
  • Нашёл дневные поезда 363У (14.11) и 357Й (15.11), разбивку по полкам
✓ Результат: 31 нижнее место в купе на 15.11 по 4 804 ₽
